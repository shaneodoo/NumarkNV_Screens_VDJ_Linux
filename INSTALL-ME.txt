║  Numark NV + VirtualDJ on Linux — install for humans  ║
╚════════════════════════════════════════════════════════╝

1. Open a terminal in this folder.

2. Run:

      chmod +x install.sh
      ./install.sh

3. Answer a couple of yes/no questions. Enter your password
   if it asks (USB permissions).

4. Plug in the Numark NV.

5. Start DJ with either:
      • App menu → “VirtualDJ (Numark NV)”
      • Or:  start-virtualdj.sh

That’s it.

If VirtualDJ is not installed yet, install the Windows
VirtualDJ under Wine first, then run start-virtualdj.sh.
