# Numark NV + VirtualDJ on Linux

Make VirtualDJ (Wine) drive your **Numark NV** on Linux: pads, **both LCDs**, and NV audio when available.

##THIS HAS ONLY BEEN TESTED ON NUMARK NV NOT NUMARK NV2##

## Install (easy)

```bash
chmod +x install.sh
./install.sh
```

Or read **`INSTALL-ME.txt`** (same steps in plain English).

Then start with **VirtualDJ (Numark NV)** from your app menu, or:

```bash
start-virtualdj.sh
```

## What you need

- Numark NV  
- Linux + Wine  
- VirtualDJ **for Windows** installed in Wine  
- About two minutes and a password once (for USB permissions)
